ANSH TRADING COMPANY WEBSITE - OLD VERSION

How to run locally:
1. Open this folder in VS Code
2. Open Terminal
3. Run: npm install
4. Run: npm run dev

How to deploy on Vercel:
1. Upload this ZIP to Vercel or push it to GitHub
2. Framework will auto-detect Vite
3. Build command: npm run build
4. Output directory: dist

Admin Panel:
- Press Ctrl + Shift + Alt + A
- Or click logo 5 times

Important:
- For permanent images, use image URLs.
- Upload preview images are not permanently saved if too large.
